# 🧠 Soft-onboarding-agent-LLM

[Soft-On-Boarding-Agent](https://github.com/kdjkdj111/Soft-On-boarding-Agent) 프로젝트의 핵심 AI 엔진이자 LLM 파이프라인 전용 레포지토리입니다.

이 레포지토리는 다수의 팀원이 참여하는 통합 프로젝트 환경에서 프론트엔드/백엔드와의 코드 충돌을 방지하고 협업 병목 현상을 해소하기 위해 독립적인 체크포인트로 분리되었습니다.

이를 통해 다른 파트의 작업에 영향을 주지 않고 LLM 기반 분석 및 추론 모델의 개발, 테스트, 유지보수를 안전하고 민첩하게 수행할 수 있습니다. 코드베이스 분석, 문서 자동화, 온보딩 가이드 생성 등 LLM에 의존하는 핵심 백엔드 프로세스를 전담합니다.
